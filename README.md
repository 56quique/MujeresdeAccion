# Proyecto PWA - App Editable

Aplicación Web Progresiva (PWA) de estructura fija con contenido dinámico editable mediante archivos JSON e integración directa con la API de GitHub.

## Estructura de Archivos
- `index.html`, `devocional.html`, `articulos.html`, `articulo.html`, `editoras.html`: Vistas HTML.
- `estilos.css`: Estilos visuales.
- `data/`: Contiene los archivos JSON de datos.
- `js/`: Lógica de la aplicación e integración con GitHub.
